# v1.0.0 — GPT龙娘 / GPT Dragon Girl

First open-source package for the original desktop v2 dragon companion.

- Original lossless desktop atlas and three AI-assisted source images.
- Offline installer and install-gpt-dragon-pet skill, with idempotence and conflict protection.
- Reproducible Pillow builder; rebuilt RGBA pixels match the original installed asset.
- Cover, nine-state overview and six-frame idle preview (120ms display timing).
- MIT code and CC BY 4.0 artwork with attribution.

Verification: see VALIDATION.json. Windows file installation was tested in an isolated directory. Existing user screenshots demonstrate desktop selection; no new full UI animation test was performed. macOS/Linux/CLI/web remain untested. This is a community asset pack, not an official OpenAI plugin.
